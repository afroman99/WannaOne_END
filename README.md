# WannaOne_END

냉연 1공장 연속소둔로 1호기(`P1-CR1-CAL01`) 센서 데이터로 만든 **실시간 이상 탐지 기준 모델**.

## 실행 방법

```bash
python analysis/01_eda.py
python analysis/02_model_compare.py
python analysis/03_realtime_baseline.py
```

- 필요한 패키지: pandas, numpy, matplotlib, scikit-learn (Python 3.14, pandas 3.0, scikit-learn 1.9에서 확인)
- 프로젝트 루트에서 실행한다. 데이터는 `data/` 폴더에 둔다(아래 "데이터 출처").
- 그림은 `figures/`에 저장된다.
- `03_realtime_baseline.py`가 메인이다. 데이터 불러오기부터 모델 학습·평가까지 처음부터 끝까지 실행한다.

## 데이터 출처

- KAMP(한국인공지능제조플랫폼) 공개 제조AI데이터셋을 제철 공정 맥락에 맞게 재구성한 **교육용 재현 데이터**다. 특정 기업의 실제 조업 데이터가 아니다.
- 사용한 파일 (`data/`, 용량 문제로 저장소에는 올리지 않음)

| 파일 | 내용 |
|---|---|
| `T-CR1-CAL01_온도.csv` | 연속소둔로 온도·제어출력 (1초, 14개 로트, 345,390행) |
| `G-02_조업이벤트.csv` | 강종변경 시각 (로트에 강종을 붙이는 데 사용) |
| `G-02_정비이력.csv` | 정비 기록 (참고용, 정답 라벨로 쓰지 않음) |

- 데이터사전상 존 배정과 파일 간 연결은 [가정]이다. 결과는 설비 특성이 아니라 데이터상 패턴으로 읽는다.

## 분석 요약

**범위:** 가열·균열존 `TC/OP-Z4~Z6`. 승온·감온 구간과 감온 전 변동 구간을 뺀 온도 유지 비교 후보 구간(322,050행, 93.2%)을 쓴다.

**EDA 주요 결론**
- 측정 공백(로트 사이, 정기수리 기간)은 보간하지 않는다. 센서 결측은 모두 로트 시작에 있다. `OP=0`은 결측이 아니다.
- 강종에 따라 출력 수준이 다르다(데이터 구성상의 baseline 이동). 그래서 원래 값으로 학습한 모델은 고장보다 로트·강종 차이를 먼저 잡는다.
- 1초 단위에서 출력은 측정 온도를 같은 시각에 반대로 따라간다(제어기 반응).
- 정비 기록 근처에서 센서 신호가 보이지 않는다. 데이터사전상 정비 기록은 배정한 값이라 **정답 라벨로 쓰지 않는다.**

**실시간 기준 모델: 누적·고정 척도 robust z 제곱합**

| 항목 | 내용 |
|---|---|
| 기준값 | 로트 시작부터 직전 1분까지의 중앙값 (과거 값만 사용), 10분부터 점수 |
| 척도 | 학습 로트에서 정한 변수별 고정값 |
| 점수 / 경보 | 6개 변수 z의 제곱합 / 학습 로트 상위 1% 초과 |
| 평가 | 사후 분석 점수(로트 기준 z, IsolationForest와 순위 상관 0.91)의 사건 22/26 재현, 경보 약 4시간에 1건 |
