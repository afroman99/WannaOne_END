## 0. 한 줄

클라우드에는 **원자료와 모델 파일을 올리지 않고**, 화면에 필요한 결과(1.3MB)만 올린다. 코드와 패키지에서 찾은 취약점은 모두 고쳤다. 팀은 포트폴리오용으로 **저장소와 대시보드를 공개**하기로 했고, 결과 업로드는 강사님 허락을 받았다(4절, 2026-10-15).

## 2. 모델의 취약점 (보안 관점)

| 항목 | 상태 |

| 결정 책임 | 추천은 계산·규칙으로만 하고 최종 결정은 정비 책임자가 한다고 화면에 적음. 생성형 AI는 판단에 쓰지 않음 |

## 3. 클라우드 배포 방법 (Streamlit Community Cloud)

1. 로컬에서 결과 파일 만들기: `python analysis/05_predict_test.py` → `python -m src.app_data` → `app_data/` (모델을 바꿀 때마다 다시)
2. `app_data/`, `deploy.toml`, `.streamlit/config.toml`, `app/`, `src/`, `requirements.txt`를 커밋·푸시한다. 모델 파일(`models/`)과 원자료(`data/`)는 올리지 않는다(`.gitignore`).
3. 팀장 계정으로 Streamlit Community Cloud에 로그인 → 저장소·브랜치 선택 → 실행 파일 `app/dashboard.py` → Advanced settings에서 Python 버전을 고른다(로컬 확인 3.14) → Deploy
4. 배포 뒤 확인: 오류가 나도 파일 경로가 보이지 않는지, 5개 화면 숫자가 로컬과 같은지(회귀 점검 대표 숫자)
5. 비공개로 바꾸고 싶어지면: `deploy.toml`의 `public = false` + `python -m src.auth`로 만든 해시를 Secrets에 넣는다
