## 1. 대상 설비

| 항목 | 내용 |
|---|---|
| 공정 | **연주(연속주조)**: 쇳물을 몰드에 부어 굳히면서 연속으로 뽑아 슬래브를 만든다. 제강과 압연 사이 공정이라 멈추면 라인 전체가 선다 |
| 설비 | 연주 설비 `P1-CC1-INS01` 한 대. 데이터의 7개 설비 중 고장 사례가 가장 많다(학습 세트 61개 시나리오, 다음 설비 18개) |
| 고장 나는 부품 | **진동장치**(몰드를 흔들어 달라붙지 않게 함, 원인: 마찰), **밸브**(쇳물 양 조절, 원인: 고착·제어 지연) |
| 지금 정비의 한계 | 고장 후 복구는 정기 교체보다 비용 3배 이상(66점 vs 20점), 정지 2배(8시간 vs 4시간). 날짜에 맞춘 정기 교체만으로는 학습 데이터 고장 51건 대부분을 막지 못했다 |

## 2. 분석 목적

- **풀려는 문제**: 설비가 고장 나기 전에, **교체로 막을 수 있을 만큼 미리** 알 수 있는가?
- **예측 문제**: 예측 시점마다 "지금부터 **24시간 안에** 고장 나는가"를 맞히는 이진 분류. 교체에 4시간이 걸리고, 인력·부품·생산 일정을 준비하려면 하루 전에 알아야 한다.
- **예측 시점**: 처음에는 데이터셋 정답이 있는 6시간마다로 정했고, 개선 단계에서 1시간마다로 넓혔다. 예측 시점까지 **끝난** 센서·정비 기록만 쓴다.
- **분석 질문**: ① 고장 전 신호가 있는가, 얼마나 일찍 나오나 ② 못 잡는 고장은 무엇인가 ③ 원인 부품까지 알 수 있는가 ④ 얼마나 정확히 예측하나 ⑤ 경보로 정비하면 비용이 얼마나 줄어드나

## 3. 정상 / 이상 정의

| 구분 | 정의 |
|---|---|
| **이상** (경보 대상) | 예측 시점부터 **24시간 안에 고장**(정답 `RISK_24H` = 1). 고장 시각은 정비 기록의 `FAILURE_DT` |
| **정상** | 고장이 24시간보다 뒤이거나, 24시간 넘게 고장 없음이 확인됨(정답 0). 24시간보다 일찍 울린 경보는 **이른 경보**로 따로 센다 |
| 판단 불가 | 관측이 끝나 24시간 뒤를 알 수 없는 시점, 정비 중인 시점. 평가에서 빼고 정상으로 채우지 않는다 |
| 신호의 정상 범위 | 학습 세트 정상 시나리오에서 정비 후 재가동 기준 변화량의 **95% 범위**. 이 경계를 1로 표준화해, 1을 넘으면 정상 범위 밖 |

## 4. 성공 기준

모델을 만들기 전에 알던 값(데이터셋 기준 예제의 검증 결과, EDA 상한)으로 정했다.

| # | 기준 | 비교 대상 |
|---|---|---|
| S1 | 검증 세트 AP가 기준 예제보다 높다 | 0.806 |
| S2 | 신호가 있는 점진 고장을 모두 고장 4시간 전까지 감지한다 | 놓치는 점진 고장 0 |
| S3 | 진짜 오경보(고장 예정이 없는데 울린 경보)가 0이다 | 0 |
| S4 | 첫 경보부터 고장까지 시간(리드타임)이 기준 예제보다 길다 | 22.4시간 |
| S5 | 정비 비용이 "아무것도 안 함"보다 낮다 | 1,056점 (데이터셋 비용 규칙) |

- 지표: AP(기준값과 상관없는 순위 능력), 재현율, 정밀도, 고장 감지율, 리드타임, 진짜 오경보, 비용. 정상 시점이 88%라 정확도는 쓰지 않는다.
- **미리 아는 상한**: 학습 데이터 고장 51건 중 돌발 고장 6건(신호 없음)과 열화가 24시간보다 짧은 6건은 24시간 앞서 잡을 수 없다. 잡을 수 있는 고장은 약 76%(39/51)다.

## 5. 데이터와 규칙

| 항목 | 내용 |
|---|---|
| 구성 | 72시간짜리 독립 시나리오 360개. 센서 5초 간격(부하, 인발 속도·부하, 몰드 진동 주파수·스트로크, 몰드 쇳물 높이, 제어 지연), 정비 기록, 정기 교체 계획 |
| 분할 | 시작 시각 순서로 학습 216 · 검증 72 · 테스트 72(정답 없음). 섞지 않는다 |
| 규칙 | 탐색·특징·모델·기준은 **학습 세트 교차검증으로만** 정한다. 검증 세트는 평가에만 쓴다. 정답 열과 예측 시점 이후 정보는 특징으로 쓰지 않는다 |
| 범위 밖 | 원인 부품 진단, 다른 설비, 남은 수명(시간) 예측, 실시간 시스템 |
| 위험 | 합성 데이터라 실제 설비에 그대로 통하지 않을 수 있다. 검증 세트 고장이 16건뿐이라 한두 건에 결과가 흔들린다 |
